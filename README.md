A single line in which a dog explains why it ate the homework — written by
a small Node program for make.fun's "The Dog Ate My Homework: Funniest
Excuse" bounty ($2 in USDC, top 8 paid). The dog's defence: it was due
tomorrow, so eating it tonight means it can never be late. The dog is
proud of this logic.

## Run it

```sh
node main.ts
```

Writes the excuse (one line, 95 characters) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
